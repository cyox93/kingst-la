# Output golden files

Written by hand from the libsigrok sources (`src/output/*.c`, `src/strutil.c`),
not generated by `kingst_la.output`. `tests/test_output.py` masks the lines with
the date or the package version (`kingst-la …`, `; CSV generated by …`,
`; from … on <ctime>`, `$date …`, `$version …`) before comparing.

Input (`SAMPLES` in the test): 40 samples at 1 MHz, enabled channels in order
CH0, CH1, CH3 renamed `SDA`, CH9 (16-channel device, so "4/16").
CH5 is disabled but toggles at samples 25..26.

| sample | 0-7 | 8-15 | 16-23 | 24-31 | 32-39 |
|---|---|---|---|---|---|
| CH0 | 00110011 | 00110011 | 00110011 | 00110011 | 00110011 |
| CH1 | 00001111 | 00001111 | 00001111 | 00001111 | 00001111 |
| SDA (CH3) | 00000111 | 11111111 | 11110000 | 00000000 | 00000000 |
| CH5 (disabled) | 00000000 | 00000000 | 00000000 | 01100000 | 00000000 |
| CH9 | 00000000 | 00001000 | 00000000 | 00000000 | 01111111 |

`_trigger` files: trigger event (SR_DF_TRIGGER) between samples 20 and 21,
i.e. libsigrok receives one logic packet with samples 0..20, the trigger,
then one packet with samples 21..39.

| File | Options | Derived from |
|---|---|---|
| `bits.txt` | defaults (`width=64`) | bits.c `gen_header()`; `receive()` SR_DF_LOGIC (space every 8th bit) and SR_DF_END flush of the 40-sample partial line (trailing space after bit 40); `strutil.c sr_samplerate_string()` |
| `bits_trigger.txt` | `width=16` | bits.c `receive()`: SR_DF_TRIGGER stores `spl_cnt` (5, line 2 started at sample 16); marker `"T:%*s^ %d\n"` with offset `trigger + trigger/8` after the next full-line flush; SR_DF_END partial line |
| `hex.txt` | defaults (`width=192`) | hex.c `gen_header()`; `receive()` SR_DF_LOGIC `"%.2x "` per 8 samples |
| `hex_trigger.txt` | `width=12` | hex.c `receive()`: only samples 0-7 of each 12-sample line are printed; trigger `spl_cnt` 9, offset `9/4 + 9/8 = 3`; SR_DF_END with `spl_cnt=4`: `sample_buf` (uint8) holds samples 32..39, printed as `sample_buf << 4` (`330`, `7f0`) |
| `csv.csv` | defaults | csv.c `gen_header()` (comment `;`, `ctime()` line, "Channels (4/16)", "Samplerate"); `dump_saved_values()` label row with `label=units` → `logic`; `process_logic()` |
| `csv_trigger.csv` | `time=true`, `trigger=true` | csv.c `gen_header()` (`sample_scale` 10^6 → `xlabels[2]` "microseconds"); `dump_saved_values()` time `out_sample_count / samplerate * sample_scale`, trigger column `%d` of `ctx->trigger`, cleared after one row |
| `csv_dedup_trigger.csv` | `label=channel`, `time=yes`, `dedup=true`, `trigger=true` | csv.c `dump_saved_values()` per packet: rows 0 and last of each packet always printed, others skipped when equal to the previous printed row (enabled channels only, CH5 ignored); time counts printed rows (`out_sample_count++`); labels `Time`, channel names, `Trigger` |
| `vcd.vcd` | none | vcd.c `gen_header()` (`get_timescale_freq(1 MHz)` = 10^6 → `sr_period_string(1, 10^6)` "1 us", `vcd_identifier()` `! " # $`, scope `libsigrok`); `receive()` SR_DF_LOGIC immediate-write path: `append_vcd_timestamp(..., FALSE)` gives `"\n#<ts> "`, each value adds `" <bit><id>"` (two spaces after the timestamp); a change of the raw 16-bit sample only on disabled CH5 gives `#25 ` / `#27 ` without values; SR_DF_END `get_max_snum_flush()` → `"\n#40\n"` |
| `vcd_trigger.vcd` | none | same as `vcd.vcd`: vcd.c ignores SR_DF_TRIGGER |
| `binary.bin` | none | binary.c `receive()`: raw logic data, 2 bytes per sample, little endian (all 16 bits, CH5 included) |
| `binary_trigger.bin` | none | same as `binary.bin`: binary.c ignores SR_DF_TRIGGER |
